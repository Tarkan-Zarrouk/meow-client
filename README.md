# MeowMod

I was curious about the new deobfuscated code for Minecraft and decided to spend some time learning how to make a mod. This is my first attempt at a Minecraft mod, and I wanted to make it as simple as possible while still being useful. I hope you enjoy it! (I love cats)

## Features

- Right Shift ClickGUI with persistent module settings and keybinds
- Draggable HUD editor opened with F8
- Customizable HUD and ClickGUI colors, fonts, and font size
- Inter font integration with persistent configuration
- Smooth OptiFine-style zoom with a separate hold key
- Chat and animated top-right alert notifications
- Optional notification timer border
- Vanilla forward-only automatic sprint
