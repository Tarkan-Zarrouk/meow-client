# MeowMod

I was curious about the new deobfuscated code for Minecraft and decided to spend some time learning how to make a mod. This is my first attempt at a Minecraft mod, and I wanted to make it as simple as possible while still being useful. I hope you enjoy it! (I love cats)

## Build

Use the Gradle wrapper with Java 25:

```bash
./gradlew build
```
